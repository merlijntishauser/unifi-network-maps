## MkDocs Material example

This folder is a ready-to-use MkDocs Material setup that renders Mermaid
diagrams generated by `unifi-network-maps`.

### 1) Generate diagrams

Run these commands from the repo root:

```bash
unifi-network-maps --include-ports --format mermaid --stdout > examples/mkdocs/docs/diagrams/network.mmd
unifi-network-maps --legend-only --format mermaid --stdout > examples/mkdocs/docs/diagrams/legend.mmd
```

These outputs are raw Mermaid (no code fences), which is ideal for MkDocs
`pymdownx.snippets` includes.

### 2) Build docs

```bash
mkdocs -f examples/mkdocs/mkdocs.yml serve
```

### Mermaid setup notes

This example uses:
- `pymdownx.superfences` with a Mermaid fence
- `pymdownx.snippets` to include the `.mmd` files

Material renders Mermaid diagrams natively when configured this way.
